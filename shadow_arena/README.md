# Shadow Arena

2D-игра на Python (Pygame) в духе соулс-лайков: арена, волны врагов,
перекат и парирование «как в Sekiro».

## Концепция

Ты один в арене. Враги идут волнами и перед ударом **вспыхивают оранжевым**.
Можно уйти перекатом или **парировать** удар точно в момент атаки: враг
оглушается и получает тройной урон. Нужно пережить 8 волн. Сложность растёт:
больше врагов, выше скорость и здоровье.

## Установка и запуск

cd shadow_arena

```bash
pip install -r requirements.txt
python src/main.py
```

Раскладка клавиатуры: латиница (или управляй стрелками).

## Управление

| Действие | Кнопка |
|---|---|
| Движение | WASD / стрелки |
| Направление удара | мышь |
| Удар | ЛКМ |
| Парирование | ПКМ |
| Перекат (неуязвимость) | Пробел |
| Пауза | Esc / P |
